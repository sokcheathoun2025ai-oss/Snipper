# 🎡 កម្មវិធីបង្វិលកងចាប់រង្វាន់ (Lucky Wheel 2026)

កម្មវិធីបង្វិលកងចាប់រង្វាន់បែប Web Application ដែលមានប្រព័ន្ធបែងចែកសិទ្ធិ **Admin** និង **User** ដាច់ដោយឡែក។

## ✨ មុខងារសំខាន់ៗ

- **ប្រព័ន្ធសិទ្ធិដាច់ដោយឡែក (Role-based Access)**៖ មានតែ Admin ប៉ុណ្ណោះដែលអាចមើលឃើញ និងប្រើប្រាស់ផ្ទាំងគ្រប់គ្រង Admin។
- **កងបង្វិលរលូន (HTML5 Canvas)**៖ មានអំពូលភ្លើងរត់ជុំវិញកង សំឡេងទិកៗ និងកាំជ្រួចអបអរ (Confetti) ដោយមិនចាំបាច់មានអ៊ីនធឺណិត។
- **ផ្ទាំងគ្រប់គ្រង Admin**៖
  - បន្ថែម / កែសម្រួល / លុប / បើក-បិទ រង្វាន់
  - កំណត់អត្រាឈ្នះ (%) និងចំនួនស្តុករង្វាន់ (ឬគ្មានកំណត់ `∞`)
  - កំណត់ចំណងជើងកម្មវិធី និងរយៈពេលបង្វិល
  - នាំចេញ/នាំចូលទិន្នន័យ (JSON) និងនាំចេញប្រវត្តិជា Excel (CSV)

## ▶️ របៀបប្រើប្រាស់

បើកឯកសារ `index.html` នៅក្នុងកម្មវិធីរុករក (Chrome, Edge ឬ Safari) ឬបើកតាម **GitHub Pages**។
